# Machine-Learning

Machine learning coursework stored as a Jupyter notebook.

[Repository](https://github.com/MirzaAlbab/Machine-Learning)

## Features

- Course notebook: Machine_Learning1.ipynb
- Interactive code and analysis in notebook format

## Technology

Python and Jupyter / Google Colab; see notebook imports for the required libraries.

## Getting started

```bash
git clone https://github.com/MirzaAlbab/Machine-Learning.git
cd Machine-Learning
```

Open `Machine_Learning1.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab. Inspect imports, install the libraries they require in your notebook environment, and update any data paths before running cells in order.

## Development and checks

Restart the notebook kernel and run the cells in sequence to check reproducibility. Record library versions and dataset sources when extending the exercise.

## Project notes

Review the notebook imports and data paths before running it. The repository does not include a requirements.txt or a pinned Python environment.
